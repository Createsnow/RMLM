# RMLM 功能模块与术语表

界面、提示语、待办、企微消息都以本表为准。新增页面或文案时先查本表，一个概念只用一个叫法。

## 一、命名原则

1. **与金蝶云星空一致**：企业 ERP 是金蝶，单据、基础资料、审核 / 反审核、过账等沿用金蝶叫法，用户不用在两套系统间换词。
2. **采用通用 ERP / WMS 术语**：领料、出库、退库、报废、结存、台账、冲销、对账、关账、分摊、核销、库位等，都是制造业物料管理的通行说法。
3. **保留业务蓝图已确认的业务词**：领用行、持有人、受让人、暂存、转交、长周期、紧急领用（先领后审）、挂账等，是业务已确认的口径，含义见下文，不改。
4. **蓝图里的内部叫法只换成界面用语**：如"代登""差异池""历史基线"，界面改为通行叫法（见第四节）。设计文档、代码注释里引用蓝图条款时仍可用原词。
5. **菜单用名词，按钮用动词**：菜单写"出库开单""对账与关账"，按钮写"签收""绑定""发起冲销"。

## 二、功能模块（电脑版菜单）

### 1. 布局：分三级

| 层级 | 位置 | 内容 |
|---|---|---|
| 一级：模块 | 顶栏 | 工作台 → 领用管理 → 仓库作业 → 对账与报表 → 基础数据 → 系统管理（按 ERP 惯例：业务 → 财务 → 基础数据 → 系统管理）。模块里没有可见功能时整个模块不显示；模块内有待办时标红点 |
| 二级：功能 | 左侧栏 | 只列当前模块的功能，每项带一句话说明和待办数；可收起成图标栏。再点某个模块时回到该模块上次打开的页面 |
| 三级：页签 | 页面内 | 一个功能下的几块内容，如 退库与报废 → 退库分摊 / 报废批次；对账与关账 → 对账差异 / 冲销 / 月末关账 |

顶栏右侧是全局工具：**扫码查找**（扫码枪或输入物料码、申请号直接打开详情，ERP 单据号、仓储条码、库位码到扫码页列出结果）、待办铃铛、头像（个人菜单）。打开过的页面在内容区上方以页签保留，切换不丢已填内容。

首页即**工作台**，按重要程度分层：① 问候 + 扫码登记 / 新建申请；② 待我处理（按类型汇总，点击直达）+ 常用功能（"我的"人人都有，"岗位功能"按角色）；③ 业务流程七个环节，标出本人要动手的环节，可点击进入；④ 数据概览（按数据范围；仓库、对账类数字只对管理与职能岗位显示）。一期验收指标、行状态分布在 统计报表 → 验收指标。

## 三、核心术语

| 术语 | 含义 | 不用的叫法 |
|---|---|---|
| 领料申请 | 使用人提出的用料需求，含一条或多条物料明细；申请号 `REQ-…` | 需求单、提需求单 |
| 审核 | 直属上级（或代理人）对领料申请同意或驳回；财务对 ERP 单据、IT 对冲销的确认分别叫"财务审核""复核" | 审批（与金蝶"审核"保持一致） |
| 出库开单 | 领料专员在金蝶开其他出库单并过账，再与申请明细对上（自动匹配或手工绑定） | 开单绑定、发料 |
| 领料出库单 | 金蝶其他出库单中"研发测试其他出库单""客供领料其他出库单"类型，系统简称 LL | 领料单（口头可用） |
| 退料入库单 | 金蝶其他入库单，退库对应的 ERP 单据，简称 TL | 退库单 |
| 报废出库单 | 金蝶其他出库单，整件报废核销用，简称 BF | — |
| 调整单 | ERP 侧差错的更正单据，须引用原单号、原单行号，财务审核，简称 TZ | — |
| 领用行 | 台账的最小单位：一个物料码对应一行，记录持有人、数量、结存、状态 | 领用记录、台账明细 |
| 物料码 | 绑定在领用行上的实物条码；接仓储时即仓储条码，未接时为系统发的 RM 临时码 | 行码、标签码 |
| 签收 | 使用人扫码确认收到实物，领用行开始计结存；必须本人，不允许代录 | 收货、领取确认 |
| 持有人 | 领用行当前的责任人；初始为使用人，转交确认后变为受让人 | 保管人 |
| 结存 | 领用数量 − 耗用 − 损耗 − 退库 − 报废 | 余额、库存（避免与仓库库存混淆） |
| 耗用 / 损耗 | 正常使用消耗 / 非正常损失（须选原因 L1–L5 并拍照） | 消耗、损坏 |
| 去向 | 耗用时登记的物料用途，字典 D01–D10 | 用途 |
| 暂存 | 物料暂不使用，放到指定库位或外出位置，不扣结存 | 寄存 |
| 转交 | 持有人把领用行交给他人，受让人确认后生效 | 移交、调拨 |
| 拆分 | 一个物料码分成多份，每份换新码；拆出 + 余量 + 损耗 = 原结存 | 分割 |
| 退库 | 还能用的物料退回仓库（实物动作），之后由领料专员开退料入库单并分摊 | 退料（指单据时用"退料入库单"） |
| 报废 | 分残料报废（按损耗清零）与整件报废（入报废箱，按批次开报废出库单核销） | — |
| 分摊 | 把一张退料 / 报废单的数量按先进先出分到中台的退库 / 报废事件上 | 匹配 |
| 核销 | 报废批次与报废出库单对上，批次结清 | — |
| 对账 | ERP 单据数量与中台明细逐单逐行比对 | 核对 |
| 对账差异 | 对账发现的差额，领料专员认领、财务 / IT 关闭 | 差异池 |
| 关账 | 月末确认当月账平，关账后该月不能录单、不能冲销 | 结账、月结 |
| 冲销 | 中台侧差错的更正：对原事件做反向事件，领料专员发起、IT 复核 | 撤销、删除（事件只增不改） |
| 代录 | 由同组成员、直属上级或领料专员代持有人登记动作，留痕并通知持有人；签收不允许代录 | 代登、代办 |
| 代申请 | 替他人提交领料申请，申请人仍为使用人，留痕并通知 | — |
| 紧急领用（先领后审） | 领料专员先交接、24 小时内补审核和 ERP 单 | 急料 |
| 挂账 | 超期未处理事项列入清单督办（周报挂账、超期挂账清理率） | — |
| 长周期 | 经上级确认的长期使用物料，不触发两周冻结，每季度确认、最长 12 个月 | — |
| 冻结 / 解冻 | 超期未处理时冻结新领用，由直属上级处理后解冻 | 锁定（"锁定"另指结存异常的领用行） |
| 历史台账 | 旧台账一次导入的只读数据，只用于查询与总量核对 | 历史基线 |
| 双轨抽查 | 新旧台账并行期每周抽 20 单比对 | — |
